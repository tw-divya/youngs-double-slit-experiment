# Young's Double-Slit Experiment – Virtual Lab
## Run (VS Code)
1. Unzip the folder, then File > Open Folder > `youngs-double-slit-project`.
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click `index.html` > Open with Live Server.
